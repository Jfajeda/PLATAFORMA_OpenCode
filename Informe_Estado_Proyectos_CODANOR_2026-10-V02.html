Glosario

Glosario de términos

Definiciones de los términos técnicos utilizados en este informe.

TérminoDefinición
RemoteRepositorio remoto configurado en Git. Sin remote, el código solo existe en local y no tiene backup automático. Se configura con git remote add origin <URL>.
git pushComando que envía los commits locales al repositorio remoto (GitHub). Sin ejecutarlo, los commits solo existen en el disco local.
CommitInstantánea del estado del código en un momento dado. Cada commit tiene un hash único (ej: c424828), fecha y mensaje descriptivo.
OWASP Top 10Lista de las 10 vulnerabilidades de seguridad web más críticas publicada por OWASP. A3 = Injection, A1 = Broken Access Control, A5 = Security Misconfiguration.
XSSCross-Site Scripting. Inyección de código JavaScript malicioso en páginas web. En el contexto CODANOR, ocurre cuando se usa innerHTML con datos no sanitizados.
CSRFCross-Site Request Forgery. Ataque que fuerza a un usuario autenticado a ejecutar acciones no deseadas. Se mitiga con tokens de sesión únicos en formularios POST.
Path traversalVulnerabilidad que permite a un atacante acceder a archivos fuera del directorio previsto del servidor. Se produce con rutas como ../../../etc/passwd.
SonarCloudPlataforma de análisis estático de código en la nube. Detecta bugs, vulnerabilidades y code smells. Ofrece ratings A-E por dimensión de calidad.
AGENTS.mdArchivo de instrucciones para el agente IA OpenCode en un repositorio. Define arquitectura, reglas críticas y contexto del proyecto para que el agente opere correctamente.
Memory.mdArchivo de estado del proyecto. Registra el historial de decisiones técnicas, versiones de módulos, componentes activos y tareas pendientes.
PSPPlataforma_Seguimiento_Proyectos. Backend Flask + 9 apps ISO/ENS. El repositorio más activo con mayor volumen de código en el ecosistema CODANOR.
plataforma.dbBase de datos SQLite en modo WAL. 19 tablas. Fuente de verdad de todos los módulos: tiquets, wiki, riesgos, fases de proyecto, configuración LLM corporativa.
LANRed de área local. El servidor Flask (puerto 5001, HOST 0.0.0.0) es accesible desde cualquier PC de la misma red. IP actual del servidor: 192.168.0.81.
Magerit v3Metodología de análisis y gestión de riesgos del Consejo Superior de Administración Electrónica. Base del módulo de riesgos ISO27001/ENS/LOPD de CODANOR.
RAGRetrieval-Augmented Generation. Técnica que combina búsqueda en una base de conocimiento (ChromaDB) con generación de texto por LLM. Usado en Wiki_CODANOR (Open WebUI + Ollama).
